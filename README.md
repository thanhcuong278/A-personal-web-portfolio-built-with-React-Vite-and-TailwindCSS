# My Portfolio - React + TypeScript + Vite

Phiên bản React hiện đại của trang cá nhân:
- Trang chủ: giới thiệu, kỹ năng, liên hệ
- Dự án demo: Pokémon API, Weather (Open-Meteo), Exchange Rate (open.er-api.com)

## Yêu cầu
- Node 18+ / npm
- (Tuỳ chọn) Playwright (E2E)

## Cài đặt
```bash
npm install

## Chạy dev
npm run dev
# Mở http://localhost:5173

## Build production
npm run build
npm run preview

## Lint
npm run lint

## Test
npm run test

## E2E (Playwright)
npm run test:e2e
